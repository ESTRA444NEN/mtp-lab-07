| Уровень | № | Задание | Реализация |
| --- | --- | --- | --- |
| Средний | 5 | Удалить запись | `Library.delete_book`, `delete_note` |
| Средний | 7 | Создать несколько таблиц | `authors` и `books` в `sqlite_library.py` |
| Средний | 1 | Создать БД SQLite и таблицу | `Library.__init__` |
| Повышенный | 6 | PostgreSQL через psycopg2 | `postgres_library.py` |
| Повышенный | 8 | Кэширование запросов | `Library.get_book` с `lru_cache`, очистка при изменениях |

Для SQLite требуется только Python 3.10+: `python sqlite_library.py`. Демонстрация создаёт базу в памяти, чтобы не оставлять файлы. Для постоянной БД передайте путь в `Library("library.db")`.

Для PostgreSQL нужен работающий сервер и `python -m pip install -r requirements.txt`. Задайте переменную окружения `LAB7_PG_DSN` со строкой подключения и запустите `python postgres_library.py`. Программа создаст таблицу `lab7_notes`, вставит, выведет и удалит запись. SQL-значения передаются параметрами. Не сохраняйте пароль в репозитории.

Проверки SQLite и параметризации PostgreSQL: `python -m unittest -v`. Для полноценной проверки PostgreSQL требуется доступ к серверу.
